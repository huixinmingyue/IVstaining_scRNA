Fig. S12 source tables
======================

slim_immune2.rds / slim_immune4.rds
  coords, n-/p- prediction scores (clusters 5, 3, 0), and
  Lgals3 / Prdx1 / Mki67 expression for two Visium sections.

he_immune2.rds / he_immune4.rds
  Low-resolution H&E arrays used only as gene-map backgrounds
  (global alpha 0.90).

FigS9B_*.csv / FigS9D_*.csv / FigS9_wilcoxon.csv
  Unmodified copies of the ancestor boxplot and Wilcoxon tables.

FigS12_wilcoxon.csv
  Wilcoxon table rewritten with NEG/POS group labels (same P).

Plotted long tables are in ../source_data_plotted/.
